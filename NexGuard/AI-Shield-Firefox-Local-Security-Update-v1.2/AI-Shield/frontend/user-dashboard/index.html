ΠΩΣ ΣΕ ΠΡΟΣΤΑΤΕΥΕΙ

Πολιτική DLP

  • 🛑 BLOCK

    Κωδικοί, API keys, private keys, στοιχεία κάρτας: δεν στέλνονται.

  • ⚠️ WARN

    Υγεία, NDA, συμβάσεις, εσωτερικά emails: ζητείται επιβεβαίωση.

  • ✂️ REDACT

    ΑΦΜ, ΑΜΚΑ, ταυτότητες, IBAN, email, κινητά: στέλνονται ως ψευδώνυμα και επανέρχονται μόνο σε σένα.

  • ✅ ALLOW

    Ονόματα και διευθύνσεις: στέλνονται κανονικά.

ⓘ

Demo: μην εισάγεις πραγματικά προσωπικά δεδομένα, credentials ή εταιρικά μυστικά. Το Gemini API free tier έχει δικούς του όρους χρήσης δεδομένων.

BROWSER EXTENSION

Η ίδια προστασία μέσα στα ChatGPT, Gemini και Claude

Το extension ελέγχει κάθε μήνυμα πριν πατήσεις Send στις σελίδες των AI και εφαρμόζει την ίδια πολιτική DLP: μπλοκάρει κωδικούς και κάρτες, ζητά επιβεβαίωση για ευαίσθητα έγγραφα και στέλνει ΑΦΜ, IBAN κ.λπ. ως ψευδώνυμα.

  1. Κατέβασε το αρχείοΠάτα «Firefox» αριστερά. Κράτα το zip όπως είναι, χωρίς αποσυμπίεση.
  2. Άνοιξε το about:debuggingΓράψε στη γραμμή διευθύνσεων about:debugging#/runtime/this-firefox
  3. Load Temporary Add-on…Διάλεξε το ai-shield-firefox-….zip που κατέβασες.
  4. Ρύθμισε τη σύνδεσηabout:addons → AI Shield → ⋯ → Options. Βάλε το API URL, το token επέκτασης και την ομάδα σου, ενεργοποίησε το Prompt Guard και πάτα Αποθήκευση.
  5. Ανανέωσε τις σελίδες AIF5 στα ChatGPT / Gemini / Claude. Δοκίμασε από τις ρυθμίσεις → «Δοκιμή πολιτικής».

  3. Load unpackedΔιάλεξε τον φάκελο που περιέχει το manifest.json.

  5. Ανανέωσε τις σελίδες AIF5 στα ChatGPT / Gemini / Claude. Δοκίμασε από τις ρυθμίσεις → «Δοκιμή πολιτικής».
